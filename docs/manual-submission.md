# Manual submission and uncertain delivery

Portal, postal and other manual channels never submit anything automatically.
After reviewing and approving a message, open **Submit manually** on the request.
Download or reveal the approved text, complete the broker's published steps and
keep its receipt. Record the date you submitted it and, if known, the confirmed
receipt date. Dates use the account timezone. A receipt is optional, encrypted
evidence; uploading one does not transmit it to the broker.

The first submission starts a response target based on its immutable legal
version. An unknown receipt produces an estimate. **Record original receipt
date** can replace that assumption later without editing the approved message.
Follow-ups do not restart the original response period. See
[response targets](response-targets.md) for calendar and holiday limitations.

Recording submission pins that exact approved snapshot and moves the request to
waiting. Concurrent submissions create one record. To change submitted text,
prepare a follow-up and approve its new snapshot. Editing an unsent follow-up
does not rewrite the original submission. Erasing the profile or account also
erases its manual submission records.

If a provider call times out after dispatch starts, an email may still have been
accepted. Automatic replay uses the same message and idempotency key only inside
the safe provider window. **Resolve uncertain delivery** lets the account holder
record an outcome after checking the provider's records, with the operator's help
when necessary. An active worker must finish or lose its lease first. Leave the
outcome unresolved if it cannot be verified. Confirmed non-acceptance returns the
current message to a draft requiring fresh review; acceptance resumes waiting.
Reconciliation never sends another email or recalls an accepted one.

A confirmed broker verification request permits optional, temporary identity
document storage only while verification remains pending and with explicit
consent. Supply information directly to the broker or decline the requirement,
then record that decision. The instance never submits stored identity documents.
