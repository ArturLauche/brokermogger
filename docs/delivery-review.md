The last CI browser retry was also investigated. Its worker fixture claimed a leftover integration job from the shared schema. CI now migrates a dedicated `bm_e2e_workflows` schema for browser journeys, preserving production queue ordering and real fenced worker execution. The standalone server and browser worker fixtures continue sharing one absolute encrypted-storage path.

A component test also needed to wait for React's asynchronous transition to finish before asserting that retry was enabled. It still checks the safe error, preserved confirmation, successful retry and fresh confirmation on reopening.

Focused PostgreSQL verification passes 39 cases across seven files, and the complete unit/component suite passes 466 cases across 71 files. Matching-final-revision full CI, production browser and interface verification are recorded in PR #35 and [implementation progress](implementation-progress.md).
