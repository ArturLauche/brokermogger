# Roadmap

Shipped in this repository: magic-link auth, minimised profiles, household double opt-in, jurisdiction packs, draft generation, approval gate, mock/sandbox/resend email, Postgres jobs, evidence, JSON/PDF reports, admin catalogue, Docker and CI.

Later, without changing the product rules:

- Operator-verified (non-demo) broker records
- Richer broker-response classification
- Follow-up drafts that still require approval
- Optional identity-document flow only when a broker actually requires it
- More jurisdiction packs with sourced legal rules

Out of scope: billing, scraping, guaranteed removal, children's profiles, a mandatory legal-reviewer queue.
